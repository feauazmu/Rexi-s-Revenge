# Rexi art pipeline (version C prototype)

A port of manus-garden's art pipeline (`Art/tools/` and the ideas of `Art/anim/`) for a 64 px Rexi, as if the game ran at 640×360. It is a prototype for a three-way comparison (Refs #9). Nothing here is wired into the renderer, and the game resolution is unchanged.

Python, run with `uv` (`uv run -q --with pillow --with numpy python scripts/art/<script>.py`). The image model is only used to edit templates; every frame is assembled in code.

## Steps

| Script          | What it does                                                                                                                                                                                        |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `palette.py`    | Reads the 40-colour master palette from `src/render/palette.ts` and defines Rexi's subset (no sky, glass, neon or foliage ramps).                                                                   |
| `templates.py`  | Reference images on the model's 240-cell grid, upscaled nearest to 2752×1536: the 64 px draft, the cast lineup with Manu as a density anchor, edit sheets of N master copies, two-tone pose guides. |
| `pixelize.py`   | manus-garden's grid recovery, unchanged in method: pitch and phase from edge energy, median of each cell centre, pale-guide removal, CIELAB snap, recursive XY-cut slicing.                         |
| `clean.py`      | Raw render → cached grid (`grid/`) → snapped, sliced, named sprites in `clean/` plus their sheet positions.                                                                                         |
| `holes.py`      | manus-garden's enclosed-hole fill (white tank top cells dropped as "pale").                                                                                                                         |
| `reduce.py`     | Exact 2:1 reduction (outline-preserving) that turned the 128 px v1 render into the 64 px draft for the later templates.                                                                             |
| `fix_master.py` | The hand pass as rules: interior robe black → `night` (pure black stays the outline), robe folds on the lit half → `robeSheen`, boot insides → `leather2`.                                          |
| `rotsprite.py`  | RotSprite: Scale2x ×3, nearest rotation at 8×, mode-downsample. Exact 90° turns use `rot90`.                                                                                                        |
| `rexi_rig.py`   | The rig (below).                                                                                                                                                                                    |
| `export_c.py`   | Frames, `anim.json`, the 4× contact sheet and the in-game mock.                                                                                                                                     |
| `audit.py`      | Lint: palette colours only, full alpha only.                                                                                                                                                        |
| `pixtext.py`    | Sprites as one-letter palette codes, for reading and for pixel patches.                                                                                                                             |

## The rig (no boiling)

- **Upper body:** every frame uses the master's head, torso and tattooed near arm, pixel for pixel. Only the two hurt frames keep their key's own head, because the expression changes.
- **Lower body:** the robe's lower half, the trousers and the boots come from a key pose.
  - Each key was generated by editing four master copies against a pose guide, never freely.
  - The rig places a key by the slot it was drawn in, then matches its head to the master's to get the bob.
  - The key's far fist is removed, along with anything above the waist except the robe streaming behind him.
- **Aiming arm:** the far arm, cut from `arm_v1`, holding the Mazo Automático (pixel text). It is pre-rotated with RotSprite into 9 angles from −90° to 90° in 22.5° steps (`parts/`) and mirrored for 16 directions. A lapel cap from the same render covers the arm's root at every angle.
- **Facing left:** the frame is mirrored, and the sleeve moves so it stays on Rexi's left arm. The near arm loses the tattoo (ink is replaced by the surrounding skin), and the aiming arm gets a small lion-and-columns emblem.
- **Code-drawn extras:** breathing (head and shoulders up 1 px), the blink, the muzzle flash, recoil along the aim, and leg shortening for the stretched air poses.

The far arm aims, not the near one. From the near shoulder, a horizontal arm would cross the chest and barely clear the body at this ¾ angle. From the front shoulder it reads clearly, and the tattooed near arm stays on screen.

## Results

- **Size:** Rexi is 64–65 px tall on a 48×72 body frame. Exported frames are 120×100 with the soles on row 89.
- **Animations:** idle 8, run 6, run-back 6, jump 4 (rise, apex, fall, land), hurt 4, shoot 4, aim 16.
- **Output locations:** frames go to `reference/manu-pipeline/frames/`, and the arm parts to `reference/manu-pipeline/parts/`.

## Palette

**No extension is needed.** The frames use 21 of the 40 master colours: outline, night, robe, robeSheen, grey1–3, marble, white, skin1–4, leather1–4, hairLight, brass, gold and light.

The snap did not hit manus-garden's failures (hues jumping to the wrong ramp), because Rexi's materials all have ramps.

One rule needed help: the model drew the robe in near-black, so it snapped to the outline colour. The hand pass moves its inside to `night`.

If the art pass wants a richer robe, the first candidate for the palette's spare slots (up to 56) is a mid robe step between `robe` and `robeSheen` (about `#3a3658`). The second is a warmer skin midtone between `skin3` and `skin4`, for muscle definition at 64 px. Neither is used here.

## Lessons (on top of manus-garden's)

- **Flash does not keep the 240-cell grid by itself.** With a lone figure it drew a 128 px Rexi on a 480-cell grid (v1), then a 98 px one on the right grid (v2).
  - What held both grid and height was manus-garden's cast lineup: Manu (78 px, already on the 240-cell grid) as the density anchor, three copies of the draft, and head-top and ground lines (v4). The three copies also gave three samples for one price.
- **Do not pass the full character sheet as a reference to an edit.** v3 redrew the sheet itself. A crop of the side view works.
- **"Raise the near arm" raised the far arm.** That turned out to be the better aiming arm.
- **The model drew the stretched air poses' legs 10–15 px too long.** Deleting the most redundant trouser rows fixes it without resampling.

## Rebuild

```sh
uv run -q --with pillow --with numpy python scripts/art/clean.py       # from grid/ (or raw/)
uv run -q --with pillow --with numpy python scripts/art/fix_master.py
uv run -q --with pillow --with numpy python scripts/art/export_c.py OUT_DIR [ARENA.png ARENA.json]
uv run -q --with pillow --with numpy python scripts/art/audit.py
```
