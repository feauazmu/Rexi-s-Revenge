# Rexi's Revenge

## Language

The user may write in Spanish, but always respond in English. Everything in the repo (code, comments, docs, commit messages, issues) is written in English.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `feauazmu/Rexi-s-Revenge` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
